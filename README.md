# Diamond Price Analysis

## Objective
Analyze how different features affect diamond prices using Exploratory Data Analysis (EDA).

## Dataset
Diamonds Dataset (Kaggle)

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

## Tasks Performed
- Loaded the dataset
- Cleaned the data
- Handled missing values
- Removed duplicate records
- Detected and removed outliers
- Calculated mean, median, mode, variance, and standard deviation
- Analyzed categorical and numerical features
- Calculated correlation
- Created bar chart, line chart, histogram, and scatter plot
- Wrote an EDA summary

## Conclusion
This project helped me understand how different diamond features affect price. I also learned data cleaning, statistical analysis, correlation, and data visualization using Python.
